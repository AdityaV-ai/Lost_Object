FINDBACK COMPLETE PROJECT - WINDOWS

IMPORTANT: This archive contains the COMPLETE original project, not just a patch.

INSTALL:
1. Make a backup/rename your current C:\LostProject folder if you need to preserve its database/uploads.
2. Extract this ZIP into C:\LostProject.
3. Choose to merge folders and replace source files if Windows asks.
4. Confirm C:\LostProject\backend\requirements.txt exists.
5. Double-click C:\LostProject\RUN_FINDBACK.bat.
6. Wait for the server message and keep the terminal open.
7. Visit http://127.0.0.1:5000/

The launcher creates backend\.venv if missing, installs backend\requirements.txt,
then runs backend\run.py. It does not delete the database or uploaded files.
